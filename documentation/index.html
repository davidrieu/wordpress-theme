Installation

Requirements

  • WordPress 6.0 or higher
  • PHP 7.4 or higher
  • MySQL 5.6 or higher

Installation Steps

  1. Download the theme ZIP file
  2. Go to Appearance > Themes > Add New
  3. Click Upload Theme
  4. Choose the ZIP file and click Install Now
  5. After installation, click Activate
Success! Your theme is now installed and activated.

Initial Setup

1. Install Required Plugins

After activation, you'll see a notice to install required plugins:

  • Elementor - Page builder (Required)
  • WooCommerce - E-commerce platform (Required)
  • Contact Form 7 - Contact forms (Required)
Tip: Click the notification banner to automatically install all required plugins.

2. Import Demo Content (Optional)

  1. Install One Click Demo Import plugin
  2. Go to Appearance > Import Demo Data
  3. Select ConnectPro Demo
  4. Click Import and wait for completion
Warning: Demo import may take several minutes. Do not close the browser during import.

3. Configure Permalinks

  1. Go to Settings > Permalinks
  2. Select Post name
  3. Click Save Changes

Theme Features

Custom Post Type: Listings

The theme includes a powerful Listings post type for marketplace items.

Creating a Listing

  1. Go to Listings > Add New
  2. Enter listing title and description
  3. Fill in listing details:
    • Type (Rent, Sale, Service, Event)
    • Price and currency
    • Location information
    • Features and amenities
    • Contact details
  4. Add featured image
  5. Assign categories and location
  6. Click Publish

User Dashboard

Frontend dashboard allows users to:

  • View dashboard overview
  • Manage their listings
  • Access favorites
  • View messages
  • Edit their profile

To create a dashboard page:

  1. Create a new page
  2. Add the shortcode: [user_dashboard]
  3. Publish the page

Search & Filters

Add advanced search functionality with the search shortcode:

[listing_search]

The search form includes:

  • Keyword search
  • Category filter
  • Location filter
  • Price range
  • AJAX live filtering
