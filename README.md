## Description

ConnectPro is a modern, feature-rich WordPress theme designed for marketplace and listing websites like Airbnb, Leboncoin, or any peer-to-peer platform. Fully compatible with WooCommerce and Elementor, it offers advanced search filters, user profiles, messaging system, and a beautiful responsive design.

Perfect for:
- Rental services
- Classified ads
- Job boards
- Real estate listings
- Service marketplaces
- Event listings
- Any connection-based platform

## Installation

### Via WordPress Admin

1. Download the theme ZIP file
2. Go to **Appearance > Themes > Add New**
3. Click **Upload Theme**
4. Choose the downloaded ZIP file and click **Install Now**
5. After installation, click **Activate**

### Via FTP

1. Unzip the theme archive
2. Upload the `connectpro` folder to `/wp-content/themes/`
3. Go to **Appearance > Themes** in your WordPress admin
4. Activate the **ConnectPro** theme

## Quick Start Guide

### 1. Install Required Plugins
After theme activation, you'll see a notice to install required plugins. Click to install and activate them.

### 2. Import Demo Content (Optional)
1. Install **One Click Demo Import** plugin
2. Go to **Appearance > Import Demo Data**
3. Click **Import** to install sample content

### 3. Configure Theme Settings
1. Go to **Appearance > Customize**
2. Set your colors, typography, header, and footer options
3. Upload your logo and favicon

### 4. Set Up Menus
1. Go to **Appearance > Menus**
2. Create menus for Primary, Footer, and Mobile locations
3. Assign them to menu locations

### 5. Configure Widgets
1. Go to **Appearance > Widgets**
2. Add widgets to Sidebar and Footer widget areas

### 6. Create Your First Listing
1. Go to **Listings > Add New**
2. Fill in listing details, price, location, etc.
3. Add featured image and publish
